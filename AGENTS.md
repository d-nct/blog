# Agent Instructions

This is a Hugo static site repository.

- Configuration is found in `hugo.toml` (and `config.toml` may exist).
- Content is located in the `content/` directory.
- Static assets are in the `static/` directory.
- Layouts are in the `layouts/` directory.
- Themes are in the `themes/` directory.

To build the site, you need to use Hugo. The GitHub Action workflow uses Hugo v0.128.0 (extended version).
